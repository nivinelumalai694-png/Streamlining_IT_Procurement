
# Streamlining IT Procurement: Automating Standard Laptop Orders with Flow Designer

## Project Overview

This project automates the **Standard Laptop procurement process** using **ServiceNow Flow Designer**.

The workflow automatically creates a **Catalog Task** after approval and assigns it to the **Hardware team**, reducing manual work and delays.

## Technologies Used

* ServiceNow
* Flow Designer
* Service Catalog
* Catalog Tasks

## Workflow

**Service Catalog → Laptop Request → Approval → Flow Designer → Catalog Task → Hardware Assignment**

## Key Features

* Automated Catalog Task creation
* Automatic Hardware group assignment
* Reduced manual work
* Easy request and task tracking
* Simple and reusable workflow

## Outcome

The project helps streamline IT procurement by making the standard laptop request and configuration process **faster, organized, and automated**.
